# Google Sheets Database Schema

Create **one spreadsheet** with one tab per table below. Row 1 of every tab
must contain exactly these column headers, in this order — the repository
layer reads/writes by column position, so the header row is the contract.

**Balance due** is always computed by summing this ledger (Opening Balance /
Invoice / Adjustment Increase add to what they owe; Payment Received /
Sales Return / Adjustment Decrease subtract). There is no stored balance
field on Customers — same principle as Product stock.

Creating a sale also writes:
- one `Sale_Items` row per product line (price/cost snapshots)
- one `Stock_Transactions` row per line (`type: Sale`)
- one `Customer_Transactions` row (`type: Invoice`, amount = total)
- optional `Customer_Transactions` row (`type: Payment Received`, amount = amountPaid)

| id, saleReturnId, productId, productName, quantity, unitPrice, lineTotal, createdAt, updatedAt |

### Purchase_Returns / Purchase_Return_Items
Same pattern as sale returns with `PRN-*` / `PRI-*` prefixes, linked to Purchases.

**Cancellations** set Sales/Purchases `status` to Cancelled and write reversing stock + ledger entries.
Partial returns use the return tables above; full cancel is blocked if any returns already exist.
